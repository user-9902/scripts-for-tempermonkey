# README

这是一个油猴脚本仓库，用于为特定网页补充一些功能。觉得不错的话，可以给我一个小星星。





### 文档结构

```js
├─── block -- 屏蔽一些广告
├─── bili_plugin -- bilibili 网站的插件、提供下载视频、视频截屏等功能
└─── video_get -- 下载任意视频
```

根目录下的每个文件夹，都是一个单独的脚本，文件夹中包含源码（src），打包后的脚本（dist.js）,打包脚本（build.js）。**对于无编程经验的使用者来说，只需关注dist.js文件即可**。





### 功能介绍

##### block

脚本实现了屏蔽bing广告、csdn广告等带来更好的浏览器使用体验

油猴配置：

- 运行时期：选择 document-end

- 用户包括：添加正则 /^http.+/


使用方法：

添加并配置完脚本即可。



##### bili_plugin

脚本实现了 bilibili音视频下载、截屏等功能。值得注意的是，bilibili声音、视频资源是分开的，脚本提供了两种下载方式（通过修改脚本中的 recodModule 变量来控制）：

- false：直接下载无音频的视频、再下载音频、自行合成（如借助 ffmpeg）。
- true：流合成方式、点击下载视频后需要完整播放视频后，方可下载。

油猴配置：

- 运行时期：选择 document-end
- 用户包括：添加正则 /^https:\/\/[^\.]+\.bilibili\.com\/.+/

使用方法：

b站视频播放视频等页面，会多出一个操作栏，点击对应操作按钮完成操作。



##### video_get

脚本实现了下载任意视频的功能，只要能播放就能下载。
很多网站存在防盗链、加密等功能用于阻止下载视频。本插件下载是基于webRTC实现的录制视频功能，只要视频能播放，就能下载（录制并下载）该视频。

油猴配置：

- 运行时期：选择 document-start
- 用户包括：添加正则 /^http.+/

使用方法：

所有网站中，将鼠标置于视频播放区域，右上角多出一个下载的小标，点击即可下载视频。（注意需要点击按钮后会重新开始播放视频，视频需完整播放后，即会自动下载）为不影响播放体验，小标会在数秒后消失，将鼠标挪出视频区域，再次挪入即可重置。





### 关于重写

油猴的脚本是单个js文件，但为方便编写，部分脚本中作者将代码进行了拆分，拆分的代码在src文件夹中。需要打包时，在node环境中执行 build.js 打包脚本，即可得到能在油猴中运行的 dist.js 。

在此基础上，您可以进行一些客制化的重写。
